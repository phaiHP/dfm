Các bước để chạy repository
B1: Clone repository. Tạo file .env
B2: Chạy lệnh pip install -r requirements.txt
B3: Chạy lệnh python download_data.py
B4: Chạy lệnh python main.py build-index
B4: Chạy một trong số các lệnh:
- python main.py ask "câu hỏi"
- python main.py retrieve "câu hỏi"
- python main.py evaluate
- python main.py ask-batch
- python main.py eval-all
